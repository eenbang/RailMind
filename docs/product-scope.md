# RailMind 产品范围

## 用户问题

用户选择火车时通常不是只追求最低价，而是在票价、用时、出发时间、舒适度和到达便利性之间权衡。传统查询工具给出完整列表，但用户仍需自行比较；RailMind 的任务是把这些取舍显式化。

## 第一版用户旅程

```text
进入 RailMind
  → 选择表单或自然语言
  → 确认上海到杭州的出行条件
  → 获得默认的 3 个推荐方案
  → 查看推荐理由与分项得分
  → 调整偏好滑块或排除条件
  → 结果实时重排
  → 比较 2–3 个方案
  → 前往外部购票平台
```

## 第一版范围

### 必须完成

- 上海至杭州的传统表单查询
- 车次类型、出发时段、价格、耗时等基础过滤
- 自然语言输入的统一入口
- 多目标评分与默认推荐
- 价格、时间、舒适性、时间合适度偏好控制
- 推荐理由与取舍说明
- 2–3 个方案的并列比较
- 响应式桌面与移动端布局

### 允许使用简化实现

- 自然语言先用规则解析，预留 LLM 接口
- 车次从本地文本加载，后续再迁 SQLite
- 舒适度为启发式评分，并标注为估算
- 日期只进入需求模型，样例数据暂不区分类别
- 购票按钮只生成搜索入口，不处理支付

### 明确不在第一版

- 全国线路覆盖
- 真实实时余票
- 智能中转组合，后续可增加换乘站换乘站台距离远近为考虑因素之一
- 动态票价预测
- 用户画像与个性化学习
- 登录、订单、支付、退改签
- 原生移动应用

## 信息架构

| 页面/区域 | 用户目标 | 首版内容 |
|---|---|---|
| 首页/出行规划 | 描述需求 | 表单、自然语言输入、默认条件 |
| 推荐结果 | 快速选择 | 默认推荐、Top 3、推荐理由 |
| 偏好控制台 | 调整取舍 | 四个权重滑块、预算和时长上限 |
| 方案详情 | 判断合适度 | 车次信息、票价、评分构成、购票入口 |
| 方案对比 | 消除犹豫 | 关键字段横向对比、最优项高亮 |

## 默认产品策略

- 默认出发时间：08:00–12:00。
- 默认权重：价格 25%、耗时 20%、舒适性 20%、时间合适度 35%。
- 默认展示 3 个方案，但允许查看全部候选。
- 时间范围、座位和预算属于硬条件；偏好权重属于软条件。
- 自然语言未提供线路时，先追问起终点；日期等非关键字段可暂用“未指定”。
- 结果为空时，明确列出冲突条件并提供一键放宽。

## 成功标准

框架阶段用以下标准判断是否可继续开发：

1. 表单与自然语言能产出同一结构的需求对象。
2. 替换数据源不需要修改页面或推荐服务。
3. 调整一个偏好后，推荐排序变化有可解释原因。
4. 每个推荐结果能指出优点、代价和相对比较对象。
5. 后续添加中转、余票或账号时，不需要重写基础出行流程。


## 具体要考虑的因素

1. 列车型号
平常我们只看动车是和谐号还是复兴号，但是大多数人都不知道复兴号和和谐号还是分了好几种不同的型号的。如和谐号就有CRH1A,CRH2A,CRH1B,CRH2B,CRH2C,CRH2E,CRH380BL,CRH380A,CRH380AN,CRH6A,CRH6F等型号，每一种型号都有不同内部布局，座椅舒适度也不同。更重要的是我们常说最美的风景在路上，多数人会选择靠窗的座位，但实际上靠窗的A座和F座也不一定正对窗口，总有几排是要面壁思过的，这时就可以根据列车型号来反推哪几排座椅是正对窗户的，此项目就是要力争适配每一个车型的座位分布，给出用户合理的建议。除此之外，不同的车型牵引电机的啸叫声也不同，如CRH1B，使用的是德国西门子的电机技术，且为国铁早期，牵引电机的VVVF啸叫声在车厢内较为明显，乘坐体验就远不如使用永磁牵引电机的CRH380AN。
2. 担当路局
不同路局的车次的服务不同，最明显的就是不同路局的普速火车餐车餐品不同，本项目就是要力求给出不同路局的车各自的优缺点以供用户权衡选择。
3. 充电插座
不同的车型充电插座分布不同，如智能动车组CR400BF-BS的二等座每5个座位有3个插座，且每个座位都能分到一个USB充电口，而CRH1B的二等座每节车厢仅有个位数的插座，长途旅行补电困难。而普速火车的硬座基本只有卫生间有插座，软卧车厢每个包间仅一个插座，走廊上仅两个插座，且25G型车、25K型车和25T型车的插座数量和分布都不同，而这是普通用户在12306上无法查询到的。本项目需要提醒用户注意，且考虑将此因素加入权重模型。
4. 时间合适度
这个不用多说
5. 价格合适度
这个也不用多说
6. 乘车车站合适度
较大的城市往往有多个火车站，如上海和杭州，此时车站也是出行时我们考虑的一个要点。如一个华东师范大学闵行校区的学生，若要乘坐普速火车前往杭州，那么就只能去上海松江站乘坐火车，路上通勤时间长，且可能会遇到小交路地铁无法到终点站，必须再等下一班地铁，总之就是路远了不好卡点进站，那么此时加点钱选更近的上海南站也不是不行，总之这也是本项目要考虑的因素，但是第一版不会实现。
7. 普速火车是否禁烟
如青藏公司的火车全列禁烟。
8. 给出国铁以外的选择
如余姚到杭州南除了国铁还有杭绍甬城际可以选择，票价比普速更低，如S2116
